# 교실 자동 냉난방 · 환기 시스템

> 「불 대수와 논리게이트로 만드는 스마트 발명품」 팀 프로젝트
> 센서 6개를 읽어 장치 4개를 제어하는 tkinter 프로토타입

교실에서는 창문을 열어둔 채 에어컨이 돌고, 아무도 없는데 난방이 켜져 있고,
공기가 답답한데 아무도 창문을 열지 않는다.
켜야 할 조건이 분명한데 사람이 매번 놓치는 문제다.
그 조건을 논리식으로 적어 기계가 대신 판단하게 만들었다.

## 실행

```bash
cd 내작업
python classroom_hvac.py
```

Python 3 표준 라이브러리와 tkinter만 사용한다. 설치할 패키지는 없다.

## 입력과 출력

| 입력 | 뜻 | | 출력 | 뜻 |
| --- | --- | --- | --- | --- |
| `R` | 자동 운영 모드가 켜져 있는가 | | `C` | 냉방 |
| `P` | 교실에 사람이 있는가 | | `H` | 난방 |
| `W` | 창문이 열렸는가 | | `A1` | 창문 닫기 경고음 |
| `T1` | 외부 온도가 28도를 초과하는가 | | `A2` | 창문 열기 경고음 |
| `T2` | 외부 온도가 18도 미만인가 | | | |
| `Q` | 이산화탄소 농도가 높은가 | | | |

입력이 6개이므로 가능한 조합은 2⁶ = **64가지**다. 전부 진리표로 적어 검증했다.

## 논리식

논리 연산은 `and`, `or`, `not` 세 가지만 쓴다. 비트 연산자는 쓰지 않는다.

```python
hot  = T1 and (not T2)      # 더위 신호가 믿을 만한가
cold = T2 and (not T1)      # 추위 신호가 믿을 만한가

C  = R and P and (not W) and hot  and (not Q)
H  = R and P and (not W) and cold and (not Q)
A1 = R and P and W and (hot or cold) and (not Q)
A2 = P and (not W) and Q
```

자동 운영 모드를 끄면 사람이 냉난방을 직접 켜고 끈다.
`R`이 선택 신호인 **2:1 멀티플렉서** 구조다.

```python
C_최종 = (R and C) or ((not R) and 수동냉방)
H_최종 = (R and H) or ((not R) and 수동난방)
```

## 출력이 켜지는 조합

64가지 중 장치가 하나라도 도는 것은 **12가지**뿐이다. 나머지 52가지는 전부 정지 상태다.

| R | P | W | T1 | T2 | Q | C | H | A1 | A2 | 동작 |
|---|---|---|----|----|---|---|---|----|----|------|
| 1 | 1 | 0 | 1 | 0 | 0 | **1** | 0 | 0 | 0 | 자동 냉방 |
| 1 | 1 | 0 | 0 | 1 | 0 | 0 | **1** | 0 | 0 | 자동 난방 |
| 1 | 1 | 1 | 1 | 0 | 0 | 0 | 0 | **1** | 0 | 창문 닫기 경고 |
| 1 | 1 | 1 | 0 | 1 | 0 | 0 | 0 | **1** | 0 | 창문 닫기 경고 |
| 0 | 1 | 0 | * | * | 1 | 0 | 0 | 0 | **1** | 창문 열기 경고 (4가지) |
| 1 | 1 | 0 | * | * | 1 | 0 | 0 | 0 | **1** | 창문 열기 경고 (4가지) |

`*` 는 온도 센서 값과 무관하다는 뜻이다. 공기 질 경고는 온도를 보지 않는다.

## 설계하면서 고친 세 가지

| 문제 | 증상 | 해결 |
| --- | --- | --- |
| `A1`에 창문 조건이 없었다 | 창문이 닫혀 있는데 "닫아 주세요"가 울림 | `W` 추가 |
| `A2`에 창문 조건이 없었다 | 창문이 열려 있는데 "여세요"가 울림 | `not W` 추가 |
| `T1`과 `T2`가 동시에 참일 수 있었다 | 냉방과 난방이 함께 켜짐 | `hot` / `cold` 로 분리 |

세 번째는 물리적으로 불가능한 입력이다. 28도를 넘으면서 동시에 18도 미만일 수는 없다.
센서가 그런 값을 보내면 고장으로 보고 온도로 움직이는 출력을 전부 멈춘다.
화면에서도 두 체크박스가 동시에 켜지지 않는다.

세 가지 모두 식만 봐서는 찾지 못했고, **진리표 64줄을 눈으로 훑다가** 발견했다.

## 검증

프로그램의 `전체 테스트` 버튼이 진리표 64줄과 실제 동작을 비교한다.

```
테스트 결과: 64 / 64 통과
```

논리식과 별개로 조건 분기 방식의 참조 구현을 따로 만들어 64가지를 교차 검증했고,
아래 네 가지가 모든 조합에서 한 번도 일어나지 않음을 확인했다.

- 냉방과 난방 동시 작동
- 창문 닫기 경고와 열기 경고 동시 작동
- 창문 상태와 경고 내용의 모순
- 온도 센서 모순 입력에서 온도 출력 작동
